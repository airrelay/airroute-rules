## 剩余限制

1. 三家账号来源尚无本轮真实下载证据；MaxMind公开派生还需解决分发/旧版本保留政策，不能只改布尔值即宣称许可问题已解决。
2. Geo是保守的大区来源融合，来源一致不证明物理位置真值，也不能证明Anycast、云/共享设施只有一个位置。不生成主动测量或虚构置信分。
3. 特殊地址空间采用明确版本化排除政策，不宣称自动穷尽所有IANA未来变化。原始Unicode域名及无法保真表达的谓词隔离，不借机扩大匹配。
4. GitHub Actions实际运行及远端release创建已核验，客户端安装层接入尚未验证；现有仓库外数据、生产数据库、凭据和历史没有被此轮改造清理。
