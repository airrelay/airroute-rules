# 地域列表、ASN 与辅助数据

本系统只读取冻结的公开资料，不进行目标主动测量。地域结果直接生成 `.list`，**没有 Geo 二进制，也不要求客户端加载它**。唯一的数据库为 `special/asn.ardb`，供客户端编译时按需展开 ASN 规则，不要求运行时常驻整库。

## 地域注册表及输出

`config/regions.json` 保留 16 个既有大区与版本化数值 ID：中国大陆、港澳、台湾、东北亚、东南亚、南亚、中亚、西亚、俄罗斯、欧洲、美国、北美其他、拉美与加勒比、大洋洲、非洲、南极。俄罗斯独立分组，不重复进入欧洲或亚洲；国家代码是输入字段，不直接冒充最终国家粒度产品。

- 中国大陆 IP：`region/cn-ip.list`，只有 `IP-CIDR` / `IP-CIDR6`。
- 中国大陆非 IP：`region/cn-domain.list`，来自成熟上游规则分类，与位置数据独立。
- 其他 `region/*.list`：只有 IP。俄罗斯服务域名保留于 `category/ru-services` 等用途集合，不回填 `region/ru.list`。

`region/cn.list` 不再存在。旧订阅需明确选择拆分后的一个或两个文件；不通过旧路径悄悄改变语义，不提供长期别名。`regions.json` 是映射元数据，不是要求客户端读取的 Geo 库。

## 固定主源与补缺

五家国家估计解析器仍保留：MaxMind GeoLite Country CSV、DB-IP Lite CSV、IPinfo Lite CSV、IP2Location LITE DB1 CSV、IPLocate Country CSV。MaxMind 的 `registered_country_geoname_id`、ASN 注册国等字段不补作位置国家。

`config/geo-policy.json` 集中定义当前顺序：**IPLocate → MaxMind → DB-IP → IPinfo → IP2Location**；`comparison_only_address_families` 将 **DB-IP IPv6** 明确设为只比较。IPv6 选择跳过 DB-IP，其他来源仍按固定顺序补缺。IPLocate 是必需主源；其整库下载、解析或完整性校验失败时构建失败，不能把备选全量顶替后仍宣称主源成功。明确禁用或本轮未选择的可选来源记录相应状态；本轮已选择且启用的来源缺凭据、下载、解析或有效输入检查失败都终止本轮，不回退旧快照或静默降级。正式主源不能禁用后宣称构建完成。

处理顺序：

1. 统一双栈地址和真实首末边界，对所有输入边界切分；不把一个宽前缀整体涂色覆盖更具体结果。
2. 每个来源内按自己的更具体范围处理；不同来源不是同一份数据，也不靠镜像增加票数。
3. 主源在该段有有效大区结果就采用；主源缺少有效结果才依次找有选择资格的备选。仅 IPv6 的备选仍可补 IPv6，不因没有 IPv4 被忽略；DB-IP IPv6 没有选择资格，但其差异仍可比较。
4. 其他来源与已选结果有冲突，保存原始国家、范围、归一化大区和所选来源，仍保留主源/顺序选中的结果。全部来源都没有有效结果才记未知。
5. 统计每个来源实际选择、覆盖、冲突及缺失贡献；来源重叠不能相加为独立覆盖或准确率。

这不是投票、置信分或人为保留比例，也不声称主源绝对准确。历史增减只是报告，不以此前的地址量决定新数据是否正确。IPv6 宽范围分别报告前缀数与精确整数地址量，并区分与本轮 BGP 观测相交及未观察到的部分。

DB-IP IPv6 只比较并不等于不下载、不解析或零成本。记录应分别展示它的原始行、范围、差异及处理耗时；当前实现仍为比较保留区间切分、排序和诊断成本，但不改变最终采用来源或生成补缺结果，也不作为额外票数。

## 冻结 IANA 资格边界

`iana-alloc-v4`、`iana-alloc-v6`、`iana-special-v4`、`iana-special-v6` 是本轮固定的必需输入。解析实际分配状态、特殊用途及 Globally Reachable 等字段，保留版本、时间、摘要和采用的范围；不沿用源码中的静态 `2000::/3` 或一份手写地址排除表作为完整资格依据。缺失、损坏、未知字段语义或解析失败明确失败。

Geo 资格是 IANA 已分配/legacy 范围扣除特殊用途地址。ASN 资格独立使用已分配/legacy 范围，并按特殊用途注册表的更具体 Globally Reachable TRUE/FALSE/N/A 处理：TRUE 例外仍可保留，FALSE 或未确定/条件项不进入正式展开。注册表允许的地址不等于已被终端分配、当前可达、实际被通告或地理位置已确认；注册表自己也不能提供位置。原始 BGP 比较观测不因资格过滤被删除。

私网、文档、组播、协议和转换用途各有语义，不能全部叫 LAN；相关可订阅列表见 [SPECIAL](SPECIAL.md)。RIR delegated、BGP、路由清单和 geofeed 不作为地域来源的替代票。

## 正式 ASN 与比较资料

`special/asn.ardb` 的唯一正式来源是 **MaxMind GeoLite ASN**，来源 ID `maxmind-asn`、格式 `maxmind-asn-csv`。使用原始 `network`、`autonomous_system_number` 和组织说明的双栈文件，按真实范围、IANA 资格及特殊 ASN 定义处理，组内无损去重/合并。它是上游的 IP-to-ASN 归属映射，不是所有来源通告的并集，也不证明物理位置或独占所有权。同一来源内先让更具体记录遮蔽宽记录，再过滤未知/特殊 ASN；不能先删掉未知子段后用宽父段重新填满。其输入缺失、下载或解析失败、双栈文件缺损不能由 BGP/IPtoASN 顶替。

RIPE RIS、Route Views MRT、IPtoASN 和其他已启用路由资料仅作**比较**。保留实际来源、采集器/peer、多起源、重叠、更具体及宽前缀统计，报告与正式 MaxMind 结果一致、不同或未覆盖的范围，不把它们写进正式 ASN 文件。一个范围在比较数据里有多个起源，应如实报告；不能宣称 MaxMind 单一映射完整表达了所有真实 MOAS。

完整 MRT 保留 collector 和 peer 身份；RIS 摘要只有聚合 origin/prefix 和 peer 数，各前缀/起源作为独立聚合声明，不能伪装成同一个实际 peer 后互相覆盖。原始宽前缀不按 `/8`、`/12` 等主观长度统一删除，默认路由 `/0`、特殊号和其他宽声明单列，不解释成整个范围的实际使用或所有权。每轮只用本轮固定比较快照，不无限追加旧通告；“本轮未见”不等于全球撤销。

特殊 ASN 依据 IANA Special-Purpose ASN 定义区分 AS0、AS_TRANS、文档、私有、保留及其他用途，保留原始输入与排除原因，不维护针对具体运营者的归属清单。观察到特殊号不自动表示上游错误；AS112 不能因为有特殊用途就被当私有号删除。

正式 ASN 校验覆盖双栈结构和语义：区分来源没有某族、真实空数据、解析失败与生成丢失。输入有有效 IPv6 而输出为空必须失败。ARDBv001 的字节契约不变，但数据来源从多源观测合并改为 MaxMind 单源正式映射；这是明确语义调整，不靠隐藏旧 Geo 库或兼容输出通过校验。

## 复用与审计

`build-domains` 从通过完整性检查的当前格式基线复用地域 IP 列表与 ASN，保留来源版本、获取时间、文件摘要和基线身份。不解析新国家库，不把本次域名快照中的新描述写成地域数据已更新。地域表变化或旧格式基线应使用完整构建。

完整争议/未知区间及来源范围留在构建诊断，不进入正式订阅；样例不等于逐条证据。按 IP/前缀、ASN 反查见 [BUILD_RECORDS](BUILD_RECORDS.md)。BGP 只是当前采集范围旁证，未见路由不证明不存在路由，见到路由也不证明地理位置。
