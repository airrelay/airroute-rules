# 覆盖与来源验收（2026-11-03）

本记录基于真实 release `2be0156400bd2c5a17d6d6c9` 与本地新冻结来源生成的候选。不是准确率评测，也不把域名条数、镜像数或文本差异称为真实网站覆盖。

## 实际来源与接入边界

26条注册链中22条资料实际下载，21条可进入公开派生/对照链。国家估计仍只有DB-IP与IPLocate；MaxMind、IPinfo、IP2Location均缺本次凭据，解析器的离线格式测试不冒充实际下载。MaxMind另有未解决的历史保留/再分发要求，默认不参与公开派生。DB-IP月度与IPLocate官方发布的双栈国家估计未因本次改动发生变化；二者一致也不等于地理真值。具体免费获取、字段与密钥条件见[SOURCES](SOURCES.md)。

新增的三条免费官方资料为Microsoft365中国云、GitHub meta和Telegram网络目录。它们是服务身份/连通性资料，不增加国家地理票数。Sukka AI已接到选择器；ChinaMax、Sukka与ACL4SSR按明确身份目录约束补充。第三方格式/镜像/共同上游不是独立证据，尚不能逐行证明的血缘明确保留不确定性。

俄罗斯原先只有少数企业条目。本次加入DLC具名银行、政府、零售、电商、教育、媒体、旅行及AI类别；不使用整个.ru、不从被封锁清单推导身份。地区IP继续对照RIPE/APNIC登记、RIS/RouteViews和geofeed，它们不作为位置票数。新报告把RIR中的CN/RU字段分别与Geo结果对照，避免将整个RIR总量误当某一国资料。

全产品去除相同谓词的重复后：14,612→15,944个谓词；新集合含1,348个未被旧集合完整覆盖的谓词，移除21个旧依赖谓词。新增地区视图与既有服务类别有交集，不能把跨产品复制相加称为新增覆盖。相同新冻结输入另用修改前的域名构建器重放，比对保存在本地验收证据中；主要变化来自选择器与准入修订，而不是将DLC更新冒充算法收益。

代表性变化：

- 大陆新增微软中国云具名端点及严格子域，例如`attachments.office365-net.cn`、`partner.outlook.cn`、`^.+\.aadrm\.cn$`。严格子域不含根域，不能改写为扩大匹配的后缀；数字验证类别补入`id6.me`等具名服务。没有直接采用全部`@cn`，因为它可能仅说明境外服务的大陆接入或公共依赖。
- 俄罗斯具名服务类别508→1,532条；region/ru另包含1,057条明确当地机构/服务谓词，仍不表示服务器位置。保留原分类路径，不引入大量新集合。
- 港澳学术机构22条、东北亚日本银行84条、欧洲英国学术38条、西亚具名伊朗服务171条进入现有地区视图。来源是明确机构/服务类别，不由国家TLD、注册地或DNS/IP反推；未有可靠身份清单的地区保持IP部分，不强行补域名。
- 流媒体补齐Prime Video、HBO/Max、DAZN、TVer、Niconico等既有免费具名类别；具体第三方CDN主机保持精确匹配。
- 微软官方连通性清单包含证书验证依赖：`ocsp.digicert.com`、`crl.globalsign.com`及`*.entrust.net`等不取得微软身份，21个此类谓词移除。GitHub meta的`*.azureedge.net`等全平台依赖也不会自动进入GitHub/Copilot。
- 开发与游戏现有目录在本次新材料中未产生可证明的额外语言覆盖，保持644/835条；不能为变大而并入无关平台。GitHub官方目录提供验证支持，独特新增为0，如实报告。
- Telegram从官方14个原始双栈CIDR无损合并为7个IPv4、4个IPv6，覆盖11,008个IPv4地址；21条服务域名不变。没有扩到整个ASN，不把服务网络当作RU或其他地区位置证据。

## ChinaMax真实差异

110,427个候选中，5,783个被明确身份目录完整覆盖；9个只是已知子项的过宽父域，只能取已经证明的子项。其余104,635个缺乏当前策略可证明的身份依据，按原因计数并保留有界样例，不能直接叫十万条真实覆盖缺口。比如`0000550xtz2.shop`等条目不会因为在ChinaMax里就被赋予大陆身份。原始固定输入仍可重放，采样数量不冒充完整候选数。

## 质量保护及验证

- 各地区分别按IPv4/IPv6地址并集、旧地址保留量及增量保护，不靠CIDR条数。首次无基线时使用本次已核准release各区地址量80%的保守底线；正常更新至少保留85%旧地址，异常增长超过1.5倍阻止发布。
- 各域名产品默认至少保留90%旧谓词语言；等价压缩不会因行数减少被当作丢失。空集合、关键来源不可用、来源下载成功但关键选择器解析失败/变空均阻止发布。Russia具名类别的已批准扩充单独放宽增长检查，其他集合不能借它隐藏缩水。
- 构建失败保留上一release；完整比较报告存Actions artifact，release仍只含28个规则文件、Geo/ASN及必要配套元数据，不发布运行报告。
- 本地真实全量计算230.061秒；额外的最终筛除/元数据绑定和完整校验43.776秒，分别计时，不能合称同一次最终代码整轮计时。最终干净源码的Linux Actions结果另列。
- 首轮真实RouteViews排序因磁盘满失败，日志保留；不清理仓库外数据、不跳过来源。改为同RIB前缀/同起源共享排序载体后，18,614,187条peer声明使用1,166,487条载体，逐peer最长前缀与多起源保留。真实前500个前缀旧/新结果一致，另有重叠前缀、独立peer与多起源随机回归。
- 本地149项测试通过（含证书依赖误归属回归）；两份完整新ARDB均由固定实际Core读取器与Python逐组解码，语义摘要一致。格式仍为ARDBv001，不修改客户端；安装层的下载/切换不由文件互操作代替。
