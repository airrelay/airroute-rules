## LAN、Real IP 与缺口

实际 special / DNS 数量和准入见 [SPECIAL.md](SPECIAL.md)：LAN 11、NTP 77、STUN/TURN 358；默认 Real IP 5、可选精确兼容 441。共享地址、组播、广播、基准测试、文档和 NAT64 独立描述。LAN 必须完整保留八段地址及三个标准本地名称；Real IP 不能混 CIDR、动作、关键字或全平台后缀。DustinWin 的 433 个精确用途候选只是可选兼容材料，不表示所有 NTP/STUN 都必须真实 IP。

仍明确的缺口：

- GoogleSearch 补充源只有会误匹配的 `DOMAIN-KEYWORD,www.google.`；不接纳。搜索类别有 94 条已支持的 Bing / DuckDuckGo / Wikimedia 等谓词，Google 提供商另列。Google Maps / Drive 不扩为整个 Google API 或共享内容根，因而不是完整逐请求服务识别。
- 共享端点无法仅凭域名区分产品；不加 MITM / UA 或根据公司国籍猜归属。
- 游戏 NAT、VPN / 覆盖网络依用户与协议而变，未建立默认全域豁免。`.lan` 是单列可选习惯，mDNS、PTR、分流 DNS 仍需客户端行为。
- 客户端没有 Real IP 名单专用订阅入口；精确/后缀到内联 `RealIpRule` 的映射及 builtin 优先关系见 SPECIAL。普通新产品目录也不自动更新客户端的旧内置目录；需要在客户端另行接入发布目录或使用其既有手动规则订阅入口。本次不改客户端。
