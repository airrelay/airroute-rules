# 探测节点 QUIC 协议

控制中心与探测节点使用独立的 QUIC 通道；Web 控制台使用 HTTP API。节点主动建立会话，控制中心推送任务，节点不轮询领取工作。本文说明公开协议和任务生命周期，不包含实际部署端点、节点标识或凭据。整体边界见 [ARCHITECTURE](ARCHITECTURE.md)，共享任务规则见 [SCHEDULING](SCHEDULING.md)。

## 信任与消息

连接使用 TLS 1.3，节点显式信任控制中心证书并校验证书，不关闭验证。证书身份不完整时拒绝静默换证。加密通道内另作独立节点凭据认证，数据库只保存凭据哈希；重置凭据会使旧认证和连接失效。

ALPN 为 `airroute-probe/1`。消息使用版本化 CBOR，带 4 字节网络序长度前缀，帧最大 2 MiB，并限制解析深度；未知版本和尾随数据被拒绝。不启用 0-RTT。

控制流承载 Hello/Welcome、Ready、Task、Finished、Heartbeat/Pong。结果通过独立双向流上传并逐条 ACK，较大结果不占用控制流。Finished 表示节点已释放执行槽，数据库接收结果本身不会提前为该节点增加工作。

## 会话与任务生命周期

- 每个节点最多一个有效会话，新连接替换旧连接。会话 ID 防止旧连接退出时误将新会话标为离线；每次派发也重新核对会话、在线及启停状态。
- 当前应用心跳间隔为 10 秒，35 秒没有应用心跳则关闭会话。明确断开立即标记离线；QUIC 底层连通不能代替应用心跳。
- 断线、停用、重置凭据或控制中心重启时，只有能证明尚未发送的工作可以立即释放。已经进入 Task 发送边界的尝试可能仍在执行或已进入节点发件箱，因此保留租约、尝试计数和恢复身份；不能仅凭断线或 ACK 丢失退款、立即重派。
- 已发送工作由结果回传或租约到期等状态规则收敛，重试仍受共享任务的有限实际执行次数约束。控制中心重启清除旧在线状态，不使 Globalping 的持久远端提交身份失效。
- 节点自动退避重连，先重传发件箱再发送 Ready。ACK 丢失时保留结果，重复回传不重复入账；永久无效收据独立保留供检查。
- 队列变动唤醒在线会话，控制中心维护计时处理未来到期工作及超时恢复。并发上限降低不打断在途工作，节点更名不改变身份；跨进程租约防止同一工作被重复领取。

进入发送前若能证明任务从未尝试传输，可以归还这一执行机会；进入发送后，部分写入和连接丢失都属于结果不确定的边界。更换会话或构建版本不能绕过这一边界。

## 容量与网络能力

每个节点独立保存并发上限，实际容量同时受节点程序报告值约束。控制中心按有效容量派发，节点也检查自身槽位；结果上传并发与执行容量分别控制，不以增加上传流扩大任务限额。

Hello 上报 IPv4/IPv6 出站能力和程序容量，网络能力定期重查并随心跳更新。控制中心按实际目标地址族过滤任务，AAAA 查询本身不代表必须具备 IPv6 出站。兼容旧版 Hello 时使用保守能力，不假定未报告的能力存在。

节点地区和 ASN 用于所需视角与网络去重，不证明目标国家或物理位置。协议成功、目标响应、路径可见及地理事实是不同层面的结论；具体可验证边界见 [VALIDATION](VALIDATION.md)。
